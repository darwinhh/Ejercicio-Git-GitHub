¿De qué trata este ejercicio?

Esta página es parte de un ejercicio académico del curso Laboratorio de Software III, donde aprendemos a utilizar Git y GitHub en un entorno colaborativo simulando un trabajo en equipo.

Objetivo del ejercicio

  • Crear un repositorio y trabajarlo en equipo con ramas y commits individuales.
  • Simular flujo de trabajo colaborativo mediante pull requests y merges.
  • Aplicar buenas prácticas de control de versiones.
